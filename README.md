# 尖塔领航 · 杀戮尖塔2 AI 决策助手

**v0.1.22 · Windows 桌面版**

- 地图分叉规划、奖励选牌、事件选项、商店购买、篝火休息与具体升级目标推荐。
- 支持事件中按界面要求一次选择多张牌；查看卡组或地图时保留原分析。
- 多套兼容 OpenAI 的接口及模型配置，可保存和切换。
- Windows 常驻通知、分状态提示音、当前位置及后两层的路线小图。
- 永久卡组、遗物、药水和游戏实际升级预览；本地错误诊断日志。

下载完整项目后，Windows 双击 **尖塔领航.exe**。需要 Node.js 22+ 与 WebView2 Runtime，操作说明见 [开始使用](开始使用.md) 和 [桌面版使用说明](桌面版使用说明.md)。

仓库不包含个人 API 配置、密钥、对局历史、错误日志或游戏本体。请在助手的 AI 设置中填写自己的接口；`config.example.json` 仅提供字段示例。社区模组及微软组件的来源和许可证分别见 `mod/SOURCE.md` 与 `desktop/SOURCE.md`。

本地运行的单人辅助原型：读取游戏状态，给出地图路线、奖励选牌、事件选项、商店组合建议，由玩家在游戏中操作。

地图界面现已支持节点连线图：绿色标记当前位置，金色标记推荐路线和下一步；点击方案或节点可用蓝色预览其他路线，“聚焦所选路线”淡化其他分支。首领位于上方，地图可滚动并定位当前房间。右侧显示接下来三站，文字路线及详细理由默认折叠。已运行的助手刷新页面即可加载这次界面更新，无需重装模组或重填 AI 设置。

## 启动

需要 Node.js 22 或更新版本。桌面组件已随项目提供，并在本机验证。Windows 双击 `尖塔领航.exe` 打开独立桌面窗口；原 `启动助手.cmd` 也会打开桌面版。服务在后台运行，日志位于项目 `work` 文件夹。也可在项目目录运行 `node server.mjs` 以前台方式运行，终止该进程即可停止服务。再次双击启动时会打开已有桌面窗口，关闭窗口留在托盘，右键托盘可退出。详见 `桌面版使用说明.md`。

## 先体验

默认进入演示模式，切换四类场景，点击“规则预览”。示例是虚构教学局面，不是准确的游戏资料。没有配置 API 时不会产生 AI 请求。规则模式的事件仅展示选项，不假装具备事件决策能力。

## 配置 AI

在“AI 设置”中填写兼容 OpenAI 的接口根地址、准确模型 ID、API 密钥。根地址通常为 `https://服务商/v1`，程序追加 `/chat/completions`。不支持 `response_format: json_object` 的服务可关闭 JSON 模式。保存后点击“AI 分析当前局面”。建议失败会显示原因，不会悄悄替换成规则结果。

密钥仅由本机服务读取，保存在 `config.local.json`；该文件为明文，请勿分享。页面不回读密钥；分享项目和打包前排除此文件及 `history/`。局面（完整卡组、遗物、药水、候选、可用地图）会发送到所配置的服务。开启“自动 AI 分析”后，实机决策界面稳定两个轮询周期会自动请求；默认关闭。相同局面缓存最近 100 份 AI 建议，避免重复消费；服务重启或修改配置会清空缓存。

## 连接游戏

采用社区 [STS2MCP](https://github.com/Gennadiyev/STS2MCP) 的只读状态接口，助手只调用 `GET http://127.0.0.1:15526/api/v1/singleplayer`，不调用操作接口。

1. 退出游戏，双击 `安装模组.cmd`，或将 `mod/` 中两个模组的四个 `.dll`、`.json` 文件复制至游戏 `mods` 目录。脚本默认目录为 `D:\SteamLibrary\steamapps\common\Slay the Spire 2`，校验文件且拒绝覆盖已有同名模组；已安装 STS2 MCP 的用户改用 `修复卡组读取.cmd`。可在 PowerShell 中运行 `powershell -ExecutionPolicy Bypass -File .\安装模组.ps1 -GameDir "你的游戏目录"` 指定其他目录。`Bypass` 仅针对这一次脚本进程，不改变系统持久设置。
2. 启动游戏，在游戏中同意并同时启用 STS2 MCP 和 Spire Advisor Deck Reader 两个模组，进入单人模式。
3. 助手“局面来源”选择“连接游戏”。
4. 在游戏中打开地图、奖励选牌、事件或商店，助手会同步显示候选。地图坐标采用模组原始 `(col,row)`；不要把它当成屏幕像素。
5. 点击 AI 分析；确认有效后可勾选自动分析。每次选择、购买或损失资源后重新读取和分析。

模组自己也提供控制接口，但本助手不使用它们。模组兼容性由上游和具体游戏版本决定，需实机验证；若无法加载，先查看游戏日志。删除复制的两个模组文件即可撤销安装，已有同名文件请先备份。原始游戏文件无需替换。

## 导入、记录与验证

“导入 JSON”支持 STS2MCP 原始状态格式；`examples/` 含四类可导入示例。每次成功建议会保存到 `history/`，界面显示最近 40 条；文件暂不自动删除。当前仅记录局面与建议，不自动标记玩家是否采纳。

运行 `node --test tests/*.test.mjs` 验证预算、药水栏、合法路线、跳过/锁定条件、非法 AI 输出、接口协议、重复请求及过时建议处理。

## 当前能力与限制

- 地图：从完整连线搜索，每个起始分支最多保留 3 条候选；每层保留 96 个分支，不是全局穷举。通用损血参数未经对局校准，不展示成真实预测；AI 可结合实际卡组在候选中选择，但不能选择被剪枝的路线。
- 选牌：完整卡组与候选描述进入 AI；仅在界面允许时提供跳过。
- 事件：锁定或已选项不参与推荐，多阶段事件变化后重算。后续删牌/升级卡牌选择界面目前提示等待，不提供专门的第二阶段卡牌排序。
- 商店：AI 可选择预算内任意商品组合，程序校验价格、库存与药水栏。组合枚举采用启发式截断；满药水栏时暂不推荐置换，需先在游戏中腾出栏位。未模拟购买导致的额外折扣、价格变化或特殊联动，买一件后应重算。
- 卡牌与遗物效果优先采用模组当场提供的描述和关键词，尚未内置完整版本数据库或战斗模拟器。缺失描述时应降低确信程度。
- 完整永久卡组由 Spire Advisor Deck Reader 补丁导出；若未启用或导出失败，助手显示“未读取”并暂停建议，避免把缺失数据当成空卡组。
- 暂不支持战斗出牌、联机建议、自动操作、胜率预测。建议质量尚未经真实对局评测。

## 项目文件

`server.mjs` 本地服务与轮询；`lib/state.mjs` 状态适配、候选与校验；`lib/ai.mjs` 提示词与 API；`lib/controller.mjs` 局面生命周期；`public/` 中文界面；`tests/` 自动验证；`examples/` 演示；`mod/` 社区桥接模组及来源说明。

接口实现参考 [OpenAI 官方 Chat Completions 文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。项目代码为此助手实现；社区模组按其 MIT 许可证单独附带。
